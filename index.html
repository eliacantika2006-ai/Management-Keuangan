TENTANG APLIKASI

Tentang UangKu

Aplikasi sederhana untuk membantu mahasiswa lebih sadar terhadap keuangannya.

₭

UangKu

“Kelola Uangmu, Atur Masa Depanmu.”

UangKu dirancang sebagai proyek pembelajaran untuk membantu mahasiswa mencatat pemasukan, pengeluaran, membuat target, dan membaca kondisi keuangan pribadi secara sederhana.

Fitur utama

  • ✓ Tambah, edit, dan hapus transaksi
  • ✓ Dashboard saldo real-time
  • ✓ Pencarian dan filter transaksi
  • ✓ Statistik dan grafik keuangan
  • ✓ Target pengeluaran bulanan
  • ✓ Insight otomatis
  • ✓ Penyimpanan LocalStorage
  • ✓ Export transaksi ke CSV
  • ✓ Responsive untuk desktop dan mobile
